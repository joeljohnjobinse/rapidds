# rapidds Stability Guarantees

## Version: 0.1.0

rapidds follows semantic versioning:

- MAJOR: breaking API changes
- MINOR: new features or behavior changes
- PATCH: bug fixes only

## Stability guarantees in v0.1.0

The following components are considered stable:

- Dataset core inspection and suggestion APIs
- InspectionReport interface
- Visualization functions
- Explicit cleaning helpers

Internal utilities may change without notice.

## Philosophy

rapidds prioritizes trust and predictability over rapid feature expansion.
Breaking changes are intentional, documented, and versioned.
